Política de Privacidade

Allan Ads Connect · Vigente desde 31 de outubro de 2026

Esta política explica como o Allan Ads Connect ("a ferramenta"), desenvolvido e usado por Allan Oliveira, acessa, usa, guarda e compartilha dados obtidos das APIs do Google. Veja também a página inicial.

1. Quais dados do Google a ferramenta acessa

Com a autorização OAuth do próprio usuário (escopo https://www.googleapis.com/auth/adwords), a ferramenta acessa pela Google Ads API apenas dados das contas de anúncio que o usuário já administra: estrutura de campanhas, grupos de anúncios, anúncios, palavras-chave, recursos (textos, imagens e vídeos), segmentação, configurações de conversão e métricas de desempenho.

A ferramenta não acessa Gmail, Google Drive, contatos, agenda ou qualquer outro dado da Conta Google além do Google Ads.

2. Como os dados são usados

  • Exibir relatórios e diagnósticos de campanhas ao próprio usuário.
  • Criar campanhas (sempre pausadas) e fazer ajustes que o usuário solicita explicitamente.
  • Registrar um log local de cada alteração feita, para auditoria do próprio usuário.

Os dados não são usados para publicidade, para criar perfis de pessoas, nem para treinar modelos de inteligência artificial.

3. Onde os dados ficam guardados

A ferramenta roda no computador do usuário. As credenciais de acesso (token OAuth) e o log de alterações ficam salvos localmente, nesse computador. A ferramenta não mantém servidor nem banco de dados próprio com dados do Google.

4. Compartilhamento

Os dados do Google não são vendidos e não são compartilhados com terceiros para nenhuma finalidade própria. Para executar os pedidos do usuário, as respostas da Google Ads API podem ser processadas pelo assistente de inteligência artificial que opera a ferramenta (Claude, da Anthropic), exclusivamente para cumprir a solicitação feita pelo usuário naquele momento.

5. Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Retenção e exclusão

O usuário pode revogar o acesso a qualquer momento em myaccount.google.com/permissions. Ao revogar, a ferramenta deixa de acessar a Google Ads API. O token e o log local podem ser apagados pelo usuário a qualquer momento, removendo os arquivos do computador.

7. Segurança

O acesso usa o protocolo OAuth 2.0 do Google. As credenciais ficam apenas no computador do usuário e não são enviadas a nenhum outro serviço além do próprio Google.

8. Contato

Dúvidas sobre esta política: allan.oliveira@pareto.plus

Privacy Policy (English summary)

Allan Ads Connect is a personal Google Ads management tool used by its developer. With the user's own OAuth consent (scope https://www.googleapis.com/auth/adwords), it accesses only Google Ads data for accounts the user already manages (campaigns, ad groups, ads, keywords, assets, targeting, conversion settings and performance metrics), to report on campaigns, create campaigns in paused status and apply changes the user explicitly requests.

It runs locally on the user's computer; OAuth credentials and a change log are stored locally only. Google user data is not sold, not used for advertising or profiling, and not used to train AI models. To fulfill a user's request, API responses may be processed by the AI assistant that operates the tool (Anthropic's Claude), solely for that request. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: allan.oliveira@pareto.plus.

Allan Ads Connect não é afiliado, patrocinado nem endossado pelo Google.
